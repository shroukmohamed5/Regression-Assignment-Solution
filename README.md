# 📊 Exploratory Data Analysis

An Exploratory Data Analysis project focused on understanding patterns, relationships, and key insights within two datasets: **Student Performance** and **House Sales**.

## 🔍 What I Did

* Data cleaning and preprocessing
* Exploratory analysis and visualization
* Statistical summaries
* Feature distribution analysis
* Correlation analysis
* Identification of important patterns and relationships

## 📁 Datasets

### Student Performance

Includes demographic, family, study, and academic performance features such as:
`Gender`, `ParentEduc`, `TestPrep`, `WklyStudyHours`, `MathScore`, `ReadingScore`, `WritingScore`.

### House Sales

Includes property characteristics and sale information such as:
`price`, `bedrooms`, `bathrooms`, `sqft_living`, `grade`, `yr_built`, `zipcode`, `lat`, `long`, and others.

## 🛠️ Tools

**Python · NumPy · Pandas · Matplotlib · Seaborn · Jupyter Notebook**

## 🎯 Goal

To extract meaningful insights from raw data through systematic exploration, visualization, and statistical analysis.
